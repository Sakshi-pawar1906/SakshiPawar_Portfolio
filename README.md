# Sakshi Pawar | Portfolio Website

A responsive, animated personal portfolio built as part of my MCA Web Technology Lab (Assignment 9) at R. H. Sapat College of Engineering, Nashik.

🔗 **Live site:** https://sakshipawar1906.netlify.app

## Features
- Home, About, Skills, Projects and Contact sections
- Loading screen, rolling headline and scroll animations with GSAP
- Smooth scrolling with Lenis
- Fully responsive for mobile, tablet and desktop
- Styled with Tailwind CSS

## Tech Stack
HTML5, Tailwind CSS, JavaScript, GSAP (ScrollTrigger), Lenis

## Run locally
1. Download or clone this repository.
2. Open the folder in VS Code.
3. Run `index.html` with the Live Server extension.

## Files
- `index.html`: page structure
- `style.css`: custom CSS
- `script.js`: animations and interactions
- `tailwind-config.js`: Tailwind colours and fonts
- `photo.jpg`: profile photo
